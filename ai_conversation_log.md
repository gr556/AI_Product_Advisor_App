# 📂 Project File Structure - AI Product Advisor

### ✅ Explanation of Key Files
- **App.js** → Entry point that loads the Advisor screen.  
- **AdvisorScreen.js** → Handles query input, recommendation logic, and state management.  
- **catalog.js** → Stores the product catalog (used as the "database").  
- **ProductCard.js** → UI component for displaying product recommendations.  
- **README.md** → Documents architecture, approach, and file structure.  
- **ai_conversation_log.md** → Contains conversations with AI used in building this project.  
- **package.json** → Handles dependencies (React Native, etc).  

This ensures clarity, modularity, and simplicity for evaluation.
